# Privacy Policy — aiq-rclone

Last updated: 2026-09-27

aiq-rclone is a personal OAuth client. Its only user is the owner of this repository, who uses it with rclone to store backup files in their own Google Drive.

## Data accessed
- The app requests only the `drive.file` scope. It can access only the files and folders that it creates.
- It does not read, index, or modify any other content in the user's Google Drive.

## Data use, storage and sharing
- Files are uploaded to, and downloaded from, the owner's own Google Drive for backup purposes only.
- OAuth tokens are stored locally on the owner's own computers. The app has no server and keeps no copy of any data.
- No data is sold, shared with, or transferred to third parties. The app does no advertising and no analytics.

## Revoking access
The owner can revoke access at any time at https://myaccount.google.com/permissions.
